#  Calculator

A simple and clean calculator built with HTML, CSS, and JavaScript.

## Features
- Addition, Subtraction, Multiplication, Division
- Handles division by zero
- Validates empty and invalid inputs
- Allows multiple calculations without restarting

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run
1. Clone the repository:
   git clone https://github.com/uossefsalahx/calculator
2. Open index.html in your browser
